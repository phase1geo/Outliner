# Changing themes

Outliner comes equipped out of the box with several different themes that change various colors used within the document.  To change the theme, simply click on the gear icon in the headerbar and select any one of the four available theme buttons just below the zoom controls.  Clicking each button will immediately change the theme of the currently selected tab.

Important Note:  If you attempt to print a document, the Default theme will be used which prints colored text on a white background to eliminate wasteful ink usage.
