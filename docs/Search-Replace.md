## Search

You can search for a given piece of text anywhere in the document by clicking on the Search icon in the headerbar.  This will reveal the search/replace toolbar, placing the cursor in the search entry field.  Enter the text to search on and hit the Enter button to perform a search for all matching text in the document.  All matches will be highlighted and the cursor will be placed on the first match.  Use the Next Match/Previous Match buttons in the search toolbar to jump the cursor to the next or previous matching search result.

## Replace

Once text has been set in the search entry field, the Replace entry field will be enabled, allowing the user to change the text of all matches to the given value or change one match at a time.  The type of replacement is controlled by clicking on the **Replace Current** and **Replace All** buttons.
