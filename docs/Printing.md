# Printing

Outliner can print any outline to a printer or file.  To print a file, select the **Export** button in the header bar and then select the **Print** menu option.

A standard print interface will be displayed.  After selecting the desired print options, click the Print button to begin printing.

## Important Notes

* The only currently supported paper to print to is standard 8.5 x 11 in the portrait orientation.
* Only the Default theme style will be used in printed documents.
