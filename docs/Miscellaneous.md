## Undo/Redo

You can undo any change that is made to a document by either clicking on the "Undo" button in the headerbar or by using the Control-Z keyboard shortcut.  This will restore the document to the same state that it was in prior to the last modification.

If you have undone any change, you can redo that change by clicking on the "Redo" button in the headerbar or by using the Control-Shift-Z keyboard shortcut.

## Depth Lines

Sometimes in large documents, it helps to determine at which level a given row is in the outline.  For the purpose, Outliner has an option, available in the `Properties` popover, which allows you to enable/disable the display of depth lines.

## Showing keyboard shortcuts

You can display all of the supported keyboard shortcuts available within the application by clicking on the gear icon in the headerbar and selecting the "Shortcut Cheatsheet" option in the resulting popover window.  This will display a stand-alone window which displays all of the available shortcuts in a paned interface.  To search for a specific shortcut, enter any portion of the text of the keyboard shortcut in the search window.  You can peruse all available shortcuts by changing the category selection picker at the top of the window.
