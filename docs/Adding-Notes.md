## Adding a note to a row

Each outliner row can have a note added to the row.  The note can have the same styling added to it that any outline row can.  To create a new note for a row, hover the cursor over the desired row so that the note button is displayed to the left of the row text.  Click on this button to show the note and place it into editing mode.  If the note for the row exists, the note button will be permanently displayed in the outline.

## Hiding/Showing a note

If a note has been associated with a row, simply click the note icon to toggle the display status of the note.

## Removing a note from a row

To remove a note from a row, click on the note icon to display the note text.  Then simply delete the note text and exit note editing.  This will delete the note and remove the note icon from display (unless the mouse cursor is over the row).
