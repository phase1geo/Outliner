## Importing

Outliner currently has the capability to open a few documentation types which include the following:

* Minder
* OPML

When a document of one of these types are imported, the information embedded within the file is converted into Outliner format and immediately saved as a .outliner file in the same directory as the original file.

To import a document, click on the Open File button in the header bar.  This will open a standard open file window.  By default, the window will open with the Outliner file filter applied.  To change the filter to open a file of the desired type, change the file type in the lower left corner selection widget.  Then simply select the file using the standard file picker.

## Exporting

Outliner currently has built-in support for exporting Outliner information as several file types, including:

* HTML
* Markdown
* Minder (versions 1.x and 2.x+)
* ODT
* OPML
* OrgMode
* PDF
* RTF
* Plaintext

To export to a given file type, select the **Export** button in the header bar, select the desired export type from the drop-down list, changing any available options, and click the **Export** button.  This will open a standard file save window.  Give the file a name and click the **Export** button to save the exported file.
