# Tags

Tags can be associated with rows in your outline by entering the **@** symbol followed by the name of the tag.  Tag names cannot have spaces in them.  Each row can have zero or more tags.  If you have created tags in the outline previously and enter the **@** symbol, Outliner will display the list of available tags in a dropdown display.  Continuing to enter characters will automatically update the contents of the dropdown list to only display existing tags that match.  Select a tag with the cursor or hit the **Enter** key when a tag is selected to insert it.  Creating new tags is just a matter of entering the tag string that you desire followed by a whitespace character (i.e., space, tab or newline) or followed by the end of the line.

Tags will be color highlighted as they are created to make them easy to see in the outline.  Though tags can be added anywhere in the row, we recommend that you add tags at the end of each row to improve visibility.

## Filtering Rows Using Tags

You can use tags to quickly filter all rows containing a given tag.  You can filter on a tag by holding the Control key and then using the mouse to click on a tag in the outline.  This will display only those rows containing the clicked tag.  At the bottom of the window, you will be notified what tag you are filtering on.  Entering the **Escape** key will escape the filtered view and bring you back to the normal outline view.
