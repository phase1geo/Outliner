## Adding a new sibling row

To create a new row that is associated within the same group immediately after the currently selected/edited note, hit the **Return** key.  This will add the new row directly below the current row and any of its descendant rows and place it into editing mode.  To add a new row above the current row, hit the **Shift-Return** key combination.  This will add the new row and immediately place it into editing mode.

## Deleting the currently selected row

If a row is not currently being edited and it is selected, hit the **Delete** or **Backspace** key to delete the row (and any of its descendant rows).

## Indenting the current row

Hitting the **Tab** key if a row is selected (or is being edited) will indent the current row, making it a child of the row directly above it.  If the row is already a child of a row, it cannot be indented.

## Unindenting the current row

Hitting the **Shift-Key** key combination if a row is selected (or is being edited) will unindent the current row, making it a sibling of the row originally containing the current row.
