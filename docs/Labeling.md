# Labeling

Labels are assigned to rows and are used for selecting a row to move other rows to using the keyboard.  When a row is labeled, its label number (1-9) is displayed next to the row.  After a row is labeled, you can use the keyboard to navigate around the outline and move selected rows to be either a sibling to or a child within the labeled row.  Labels are not output in exported outlines because they do not represent outline data (only markers for outline manipulation).

You can assign 9 labels within the outline (a row can only have one label assigned to it).
