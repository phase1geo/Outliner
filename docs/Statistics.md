# Statistics

Document statistics are always available for view for the current document and include information such as character count, word count and row count.

## Displaying the current document statistics

To show the current document statistics, simply click on the statistics button in the headerbar.  This will display a small popover window displaying the current results.  Clicking on the button again (or anywhere else in the window) will hide the statistics popover.
